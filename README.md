# Login and Registration Page

A sliding login / registration page. Panels animate when you switch between the two forms.

**Live demo:** https://moh9180812-cyber.github.io/Sign-Up-Project/

## Features
- Switch between Login and Registration with animated panels
- Sliding transitions written with CSS and JavaScript
- Layout for the two forms and welcome panels

## Built with
HTML, CSS, JavaScript

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/Sign-Up-Project.git
cd Sign-Up-Project
```
Open `index.html` in your browser. No build step or install needed.
